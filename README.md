# PythonCircleProject 🐢

A beginner Python project using Turtle Graphics to draw a square with a turtle.

## About the Project

This project demonstrates basic Python programming concepts using the Turtle graphics library.

The program:
- Creates a turtle object.
- Changes the turtle's shape and color.
- Uses a `for` loop to draw a square.
- Moves the turtle forward by 100 units.
- Turns the turtle right by 90 degrees.
